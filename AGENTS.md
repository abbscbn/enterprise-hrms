# enterprise-hrms

## Teknolojiler

- Backend: Python, FastAPI, Flask
- Frontend: React, TypeScript, Redux Toolkit, RTK Query
- Database: Oracle Database, SQL, PL/SQL
- Messaging: RabbitMQ
- İleride: Docker Compose ve mikroservis mimarisi
- Version control: Git ve GitHub

## Çalışma Kuralları

1. Yalnızca açıkça istenen kapsamda değişiklik yap.
2. Büyük değişikliklerden önce plan sun ve onay bekle.
3. Oracle üzerinde CREATE, ALTER, DROP, TRUNCATE, INSERT, UPDATE, DELETE, MERGE veya PL/SQL çalıştırmadan önce açık onay al.
4. Veritabanı bağlantı bilgilerini, şifreleri ve diğer gizli bilgileri kaynak koduna veya Git'e ekleme.
5. Veritabanı değişikliklerini versiyonlanabilir SQL/PLSQL scriptleri olarak repository içinde tut.
6. Veritabanı scriptlerini kullanıcı onayı olmadan çalıştırma.
7. Git commit, push, merge, rebase veya branch silme işlemlerini izinsiz yapma.
8. Bağımlılık kurma, test çalıştırma veya uygulamayı başlatma işlemlerinden önce izin iste.
9. Yıkıcı komutları çalıştırma; gerekirse önce etkilerini açıkla ve onay al.
10. Backend, frontend ve database katmanlarını birbirinden ayrı tut.
11. PL/SQL package kullanımını önceliklendir; iş kurallarının hangi katmanda bulunacağını açıklayarak tasarla.
12. Kod ve dosya isimlerinde tutarlı İngilizce adlandırma kullan.
13. Açıklamalarını ve görev özetlerini Türkçe yap.
14. Görev sonunda değişen dosyaları ve yapılan işlemleri özetle.
